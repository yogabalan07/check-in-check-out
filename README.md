# 📌 About the Project

The **Class D Hackathon Check-In / Check-Out System** is a web-based attendance management platform designed to handle participant movement during a hackathon.

Instead of maintaining manual attendance sheets, participants can scan a QR code and enter their register number to record their:

- Check-In time
- Check-Out time
- Hall
- Attendance status
- Late Check-In
- Early Check-Out

The system provides a centralized **Admin Dashboard** for organizers to monitor attendance and generate reports.
